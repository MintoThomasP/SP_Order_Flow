2. Inbound Webhook Integration (`POST /api/v1/peecho/webhook/`)

The inbound gateway endpoint accepts order creation events from Peecho. It guarantees non-blocking execution, responds with HTTP 201 Created within < 400 ms, and offloads heavy file streaming to Celery workers.

Environment Base URL & Endpoint Authentication & Security
Production Gateway https://orderflow.silverpointprint.com/api/v1/peecho/webhook/ HMAC-SHA256 (X-Peecho-Signature) + TLS 1.3
Staging Sandbox https://staging.orderflow.silverpointprint.com/api/v1/peecho/webhook/ HMAC-SHA256 Sandbox Secret Key (is_sandbox = True)

Security Verification & Deduplication Mechanics

1. Signature Verification: The raw request payload bytes are hashed with HMAC-SHA256 using the configured PEECHO_WEBHOOK_SECRET. If the calculated hex signature does not match the X-Peecho-Signature header, the request is immediately dropped with HTTP 401 Unauthorized.
2. Payload Deduplication: A SHA-256 hash of the payload is computed and compared against PeechoPayloadLog. If a processed log with the identical hash already exists, the gateway returns HTTP 200 OK (DUPLICATE) without generating duplicate shopfloor jobs.

4. Error Handling & Exponential Backoff Architecture

To defend against transient network failures, Peecho maintenance windows, or DNS interruptions, Silver Point's Celery task worker executes a truncated exponential backoff retry policy:

Retry Attempt Delay Window Worker Behavior & Failover Mitigation
Attempt 1 +30 seconds Immediate fast retry for transient socket resets or TLS negotiation drops.
Attempt 2 +2 minutes (120s) Secondary retry accommodating Peecho gateway rolling deployments.
Attempt 3 +10 minutes (600s) Intermediate retry window; warning alert logged to Order Notification Center.
Attempt 4 +1 hour (3600s) Final automated long-poll attempt prior to Dead-Letter Queue (DLQ) escalation.
DLQ Escalation Manual Reconciliation Shipment flagged with peecho_synced = False. Staff alerted via Notification Center for 1-click manual retry upon Peecho service restoration.
⚠ Idempotency & Safe Retry Guarantee
All outbound shipment requests include the immutable peecho_order_id. Peecho's gateway can safely receive duplicate submissions without creating multiple shipments or misaligning parcel states.

6. Extended Enterprise API Modules

6.1 Dynamic Price Calculation API Engine (`calculate_pod_quote`)

Silver Point exposes an algorithmic quote endpoint enabling Peecho's checkout widgets to query exact real-time manufacturing costs across all product configurations:

Cost Formula: Unit Cost = Base Fee + (ceil(Pages / 2) * Sheet Rate) + Binding Cost + Lamination + Foil Stamp

6.2 Automated Invoicing & Statement of Account (SOA) Framework

Using ReportLab, the system compiles compliant corporate Tax Invoices (PeechoInvoice) grouping fulfilled orders into weekly or monthly billing cycles. The invoice PDF is generated dynamically, including TRN/VAT numbers, itemized line breakdowns, and payment bank coordinates in EUR and USD.
